# Almiyah-Odoo — Complaints Management Module

Academic team project developed at the National Higher School of Computer Science (ESI Algiers) during the 2024/2025 academic year.

## About the Project

This project consists of a custom **Odoo module** designed to automate and improve the complaints management process of a public water distribution company.

The solution covers the complete complaint lifecycle, from registration to processing, communication with the complainant, resolution and archiving.

## Main Features

- Complaint registration and tracking
- Public web form for submitting complaints
- Automatic generation of complaint receipts
- Complaint categorization by origin and type
- Priority and urgency management
- Assignment of technical or commercial teams
- Technical intervention tracking
- Management of commercial review commissions
- Communication history with complainants
- Email and SMS notifications
- Satisfaction surveys after complaint resolution
- Automatic complaint archiving
- PDF reports for interventions and communications
- Dashboard indicators for complaint monitoring

## Roles

The application supports several actors involved in the complaint management process:

- Customer service agents
- Agency manager
- Technical intervention teams
- Commercial teams
- Monitoring unit
- Complainants

## Technologies

- Odoo Community
- Python
- XML
- Odoo ORM
- Odoo Views & Security
- Reports and automated actions

## Project Context

The project was carried out as part of the **Integrated Management Software (PGI)** course at ESI Algiers.

It was developed collaboratively as a team project and includes custom models, views, access rights, reports and workflow-related features.
